五百塊錢的化學維生素跟五塊錢的青椒到底差在哪？

版主　渡鴉

這是我上週跟那位獸醫哥們在熱炒店喝到第三瓶啤酒時，他指著桌上一盤空掉的炒青椒問我的問題。他說他診所最近接到一個案子，一隻天竺鼠因為嚴重的壞血病送到急診，後肢無力、牙齦滲血，飼主哭得稀里嘩啦，說自己每天都往水瓶裡加最貴的維他命 C 滴劑。我聽完直接翻了個白眼，這就是標準的「維生素 C 恐懼症」下的韭菜行為。我們這群養天天的人，真的很容易被廠商那套「牠們無法合成維他命 C」的說法嚇到失去理智，最後買了一堆成本不到售價 10% 的垃圾。

先說那個數據，一隻成年天竺鼠每天只需要 10 到 30 毫克的維他命 C 來維持生理運作。你拿市面上那些兩百毫升要賣你六、七百塊的補給液來看，裡面的抗壞血酸含量算一算，可能連一顆柳丁的量都不到。重點是，維他命 C 這種東西極度不穩定，遇到光、遇到水、遇到空氣半小時就氧化光了。你把那幾滴精華滴進水瓶裡，半天過去，你家那隻豬喝下去的其實只是帶有酸味的過期白開水，但你心裡覺得盡了義務，這就是最可怕的行銷陷阱。

我家那隻「阿肥」就是活生生的例子。天竺鼠的聽覺頻率範圍大概在 54 赫茲到 50,000 赫茲之間，這比人類敏銳得多。最誇張的不是牠能聽到什麼，而是那種「0.5 秒的制約反應」。只要我手稍微碰到廚房裡那個裝蔬菜的塑膠袋，發出那種極短促的摩擦聲，大概不到一秒，客廳就會傳來驚天動地的「Wheek! Wheek!」慘叫聲，搞得像我三天沒餵牠一樣。這種神經連結之深，深到牠們甚至能分辨塑膠袋的厚度。裝零食的厚袋子跟裝青椒的薄袋子，牠們聽出的頻率完全不同，回應的音量也不一樣。

這種「求食制約」背後其實藏著一種生理代價。天竺鼠的代謝率高得嚇人，牠們的小腦袋瓜裡幾乎把所有的資源都分配給了聽覺與消化系統的聯動。當牠們聽到聲音、分泌唾液、神經元瘋狂放電的時候，其實是在消耗能量去換取高纖維的補充。但很多飼主被這種可愛的慘叫聲制約了，反而回過頭去買那些標榜「高單位 C」的壓縮飼料。

我有次仔細拆解過某家知名進口品牌的天竺鼠飼料成分表，原料第一位是提摩西草粉，第二位是豆莢皮，第三位是大豆粉。這其實沒問題，但你看那個「穩定型維生素 C」的添加量，標註是每公斤 400 毫克。聽起來很多對吧？但飼料工廠在擠壓成型時，高溫會破壞掉至少三成的活性，等那包飼料漂洋過海來到台灣，放在寵物店燈光下烤兩個月，你餵給牠的時候，剩不到 100 毫克。結果你還是得靠那 0.5 秒的塑膠袋聲，從冰箱掏出那顆兩塊錢的青椒。

我獸醫朋友常罵，很多飼主寧願花兩千塊買那種「特調草粉」或「高效能補給劑」，也不願意每天洗兩片新鮮的深綠色葉菜。這其實是一種心理補償，因為洗菜、切菜、觀察牠們排便狀況很累人，但買一罐看起來很專業的保健品很簡單。這種「懶人飼養學」支撐了寵物店裡那些毛利率高達 60% 以上的保健品專區。你以為你買的是牠們的健康，其實你買的是你的罪惡感抵扣券。

再講更細一點，天竺鼠對特定音頻的敏感度，其實是牠們在野外作為被掠食者的生存本能。當牠們把這種本能轉移到「期待維他命 C 來源」時，這對牠們的神經系統其實是一種高壓。如果長期聽得到聲音卻吃不到東西，牠們的皮質醇水平會飆升。這也是為什麼我一直跟身邊的人說，不要拿塑膠袋聲去逗弄牠們。你以為只是開個玩笑，但對牠們來說，那是整個神經系統被強行啟動後的失落。

我認識一個住在北歐的朋友，那邊的天竺鼠飼養文化更硬核。他們幾乎不碰這些工業化的滴劑。他們會計算每克羽衣甘藍、紅椒、綠花椰菜莖的營養密度，然後精準地在早晚餵食。他們那邊的獸醫甚至會開「食材處方箋」，而不是叫你回家點滴劑。相比之下，我們這邊的討論區還在吵哪牌的 C 滴劑比較甜、豬豬比較愛喝。拜託，牠們愛喝是因為那裡面加了果糖或甜味劑，這對天竺鼠脆弱的腸道菌群來說簡直是定時炸彈。

天竺鼠的腸道就像一個不停轉動的發酵槽，需要大量纖維去推動。當你因為擔心維他命 C 不夠而給了過多含糖量高的保健品或水果，那團東西在腸道裡發酵產生的氣體，會讓牠們痛到在籠子裡發抖。我有次半夜接到一個飼主電話，說牠家天天突然不吃不喝、肚子鼓得像皮球。問了半天，才發現是那天因為看牠「Wheek」得可憐，多給了兩片甜度超標的富士蘋果。那一刻我真的覺得，天竺鼠的這種制約反應，有時候反而成了牠們的詛咒。

我們常常陷入一種數字迷思，覺得 1000 毫克一定比 100 毫克好。但在生物利用率面前，這些數字都是虛的。就像我跟我朋友聊的，一盒兩百塊的維他命 C 錠，原料成本可能不到五塊錢，剩下的都是行銷、包裝跟物流費用。如果你真的愛牠，把那個錢省下來，去超市買一袋最新鮮的黃椒，那種清脆的聲音對牠來說才是真正的靈魂救贖。

那天在熱炒店喝完，我回家看著阿肥，我故意輕輕撥了一下垃圾袋，牠馬上從草架跳起來，用那種幾乎要震破耳膜的音量對我尖叫。我摸摸牠的頭，給了牠一小塊青椒。我看著牠瘋狂咀嚼的樣子，心裡想的是，還好我沒把那五百塊拿去買化學水。這種 0.5 秒的奇蹟，不應該建立在那些虛假的包裝承諾上，而是建立在我們能不能看透那些行銷話術，回歸到最原始的、真正有意義的生理需求。

說到底，我們這些飼主有時候比天竺鼠還容易被制約。牠們是被聲音制約，我們是被標籤上的「高效」、「專業」、「必須補給」這些字眼制約。廠商抓準了你怕牠不在了、怕牠生病的心理，把最廉價的抗壞血酸裝進漂亮的瓶子裡，然後看著我們這些韭菜一箱一箱地搬回家。這場關於維他命 C 的集體焦慮，到底什麼時候才會結束？
