你的天竺鼠半夜突然「腳軟」拖著走，不一定是癱瘓，請先檢查牠的齒齦顏色。

版主　Scholar

半夜三點看到天竺鼠拖著後半身在籠子裡爬，那種衝擊力真的不亞於看到恐怖片。我上個月才接過一個急診，飼主是一個大男生，眼眶紅紅地衝進診間，開口第一句話就是「醫師，牠癱瘓了，牠是不是脊椎斷了？」那隻三歲的小長毛天竺鼠就縮在提籠角落，後腳確實像兩根軟掉的麵條。

在你們瘋狂 Google「天竺鼠癱瘓」、「脊椎損傷」或是「維他命 C 缺乏症」之前，我通常會先叫飼主做一件很簡單的事：把牠的嘴唇翻開。

這不是在開玩笑，也不是在檢查牠有沒有蛀牙。我要你看的是齒齦的顏色。如果是蒼白的，甚至是那種像沒塗漆的白牆顏色，那你的天竺鼠現在面臨的可能不是神經系統的問題，而是嚴重的內出血或是貧血造成的急性虛弱。

很多飼主會把「沒力氣走路」跟「神經性癱瘓」搞混。真正的癱瘓，通常是因為脊椎受損或神經壓迫，這時候你捏牠的後腳趾縫，牠可能完全沒反應。但如果牠是因為「腳軟」而拖著走，當你捏牠的時候，牠可能還是會縮，只是牠全身的肌肉已經沒辦法支撐起那幾百公克的體重了。

天竺鼠這種生物在演化上是非常極端的。牠們是完美的受獵者，基因裡刻著「就算快死了也要裝沒事」的代碼。這導致牠們的生理反應非常劇烈，一旦表現出症狀，通常都已經是到了臨界點。我們在臨床上常看到的「腳軟」，很多時候跟一種叫做「維他命 C 缺乏症」的教科書病名沒什麼關係，雖然大家都愛提這個。實際上，更多是因為牠們體內某些看不見的發炎、甚至是膀胱結石導致的劇烈疼痛，讓牠們放棄了行走。

我記得那隻三歲的長毛天竺鼠，翻開齒齦一看，慘白得嚇人。這根本不是什麼神經問題，後來的超音波顯示牠的腹腔裡全都是血，那是典型的肝臟腫瘤破裂。在這種情況下，身體會把所有的血液優先供應給心臟跟大腦，四肢的末梢循環會被犧牲掉。所以牠不是不想走，是牠的後腿根本沒有油了。

這就是為什麼我說半夜搜尋症狀是很危險的事。你會搜到一堆關於「壞血病」的資訊，然後急著去藥局買人用的維他命 C 滴劑往牠嘴裡灌。但如果牠是因為腹腔內出血或是急性腎衰竭造成的虛弱，你強行餵食只會讓牠在最後的時刻更加緊迫。

天竺鼠的骨骼結構很特殊，牠們的骨盆腔跟脊椎其實相對脆弱。如果是從高處摔下，那確實可能是骨折或脫位。但如果牠是平地走著走著突然就拖著後腿，請一定要冷靜下來，觀察牠的呼吸是不是很快？耳朵摸起來是不是冰涼的？

如果是冰冷的耳朵加上發白的齒齦，這是一個明確的警訊：牠正在休克。這時候你需要的不是找脊椎名醫，而是找一家有供氧設備和靜脈注射能力的急診室。

我也遇過那種真的是因為缺鈣或電解質不平衡導致抽筋式腳軟的例子。這通常發生在剛生產完的母鼠，或是長期飲食極度單一的個體身上。天竺鼠對鈣磷比例的要求非常精確，一旦這個天平歪了，肌肉收縮就會出問題。這時候的腳軟，看起來很像中風，但其實是生化層面的崩潰。

我常跟飼主說，不要被牠們那個圓滾滾、好像沒脾氣的外表騙了。天竺鼠的代謝率極高，牠們的一小時大概等於我們的一天。如果你在半夜發現牠拖著腳走，而你選擇等到明天早上門診開門，那這八個小時對牠來說，就像是你在加護病房外等了八天一樣漫長且危險。

你要做的第一步，絕對不是去翻論壇看別人的經驗談。每個品種的天竺鼠，從短毛到泰迪或是謝德蘭，雖然外觀不同，但牠們隱瞞病痛的專業程度是一樣的。你唯一能做的可靠鑑別，就是看黏膜顏色。健康的齒齦應該是粉嫩的玫瑰色，這代表血紅素正帶著氧氣跑遍全身。

如果顏色是對的，但腳還是不動，那你再去考慮是不是脊椎問題。如果是白的、紫的、或是灰的，請立刻拿起車鑰匙。

這不是在嚇唬你，這是在診間看過太多「我以為牠只是累了」或是「我想說先餵點營養膏看看」的悲劇後，唯一能給出的真誠建議。天竺鼠的生命力很強韌也很脆弱，這種矛盾感只有養過的人才懂。牠們可以陪你五六年，也可以在五六個小時內就跟你告別。半夜的恐慌通常來自於未知，而當你翻開牠的嘴唇看到那一抹慘白時，未知就變成了已知的戰鬥。

我們這些當獸醫的，最怕的不是飼主半夜打電話來問問題，而是怕飼主自己當起 Google 醫師，最後送過來的時候，遺體已經冷了一半。那一抹齒齦的顏色，就是牠們在最後一刻發出的、最微弱也最清晰的求救信號。
