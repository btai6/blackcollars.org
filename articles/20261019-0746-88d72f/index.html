別再因為哈士奇半夜對著天花板唱歌就想拿枕頭壓住牠的頭了

版主　Scholar

我診所上週才剛送走一隻九歲的哈士奇，叫阿魯。主人半夜三點把它拖進急診室時，整個人都快崩潰了，說阿魯從凌晨一點開始就在客廳發出一種像是在跟祖先通靈的長嚎，鄰居已經開始敲牆壁。這位飼主跟我說，他本來以為是阿魯在發神經，畢竟這品種的腦回路跟一般狗不太一樣，他甚至還錄了影想發到Threads上面取笑自家狗。但我看了一眼阿魯的站姿，那種後腳稍微往內扣、背部隆起一點點的弧度，我就知道這絕對不是什麼想找人吵架。

很多人養哈士奇是被那種帥氣又帶點呆萌的長相騙了，卻沒搞清楚這種來自西伯利亞的北極犬，牠們的身體構造與能量代謝邏輯，跟你在公園看到的柴犬或拉不拉多完全是兩碼子事。在極地環境裡，哈士奇有一種特殊的「代謝切換」能力，牠們可以在極低進食的情況下，維持高強度的奔跑，這得歸功於牠們極致的骨骼結構與肌肉協調性。但這種演化上的優勢，到了現代都市的客廳裡，反而成了飼主最容易忽視的奪命符。

當一隻哈士奇開始半夜嚎叫，我們習慣性地會去想牠是不是無聊、是不是想出去散步，或者是看到什麼不乾淨的東西。但你要知道，哈士奇的痛覺閾值其實很高，這也是基因遺傳下來的特點，如果不耐痛，在零下四十度的冰原上受一點小傷就哀嚎，那只會引來掠食者。所以當牠們真的開始發出那種低沉、斷斷續續且頻率固定的長嚎時，通常代表體內的疼痛已經跨過了那個演化設定的防禦門檻。

我最常在診間跟飼主解釋，哈士奇的髖關節與脊椎問題，往往被牠們旺盛的精力給掩蓋了。你看牠下午還在公園追球追得跟瘋子一樣，晚上回家卻開始對著牆角乾嚎，這不是人格分裂，而是因為運動後的發炎反應在靜止下來後才開始發作。這跟我們人類運動傷害很像，動的時候不覺得，坐下來半小時才發現腳踝腫得跟豬蹄一樣。但狗不會說話，哈士奇表達「我骨頭在痛」的方式，就是用牠們最擅長的聲帶共振。

這時候你要注意的不是牠叫得大不大聲，而是牠「怎麼站」。如果牠在叫的時候，後腿頻繁換手支撐重心，或者是一坐下來就顯得小心翼翼，那就是該照 X 光的時候了，而不是去買什麼抗焦慮噴霧。我碰過太多案例，飼主總覺得「牠還能跑啊，怎麼會有事？」這種觀念真的會害慘牠們。哈士奇的關節腔內壓力感應非常敏銳，尤其是這種品種特有的髖關節發育不良（CHD），在半夜氣溫降低、氣壓改變時，那種鑽心的痛是無法透過睡覺緩解的。

再來講講那種「代謝後的能量殘留」。有些哈士奇半夜叫，是因為牠的骨骼結構正在給大腦傳遞錯誤訊號。牠們的身體是為了長途跋涉設計的，當都市生活的活動量不足以支撐牠們骨骼與肌肉的正常張力時，那種肌肉不自主的抽搐或神經壓迫，會讓牠們產生極大的焦慮感。這不是運動量不夠的問題，而是牠的骨骼結構已經出現了微小的位移，導致神經傳導受阻。

我常跟飼主開玩笑說，養哈士奇就像養了一台高性能越野車，但你每天只開它去買菜，久了變速箱一定出問題。那種半夜的哀嚎，往往是變速箱——也就是牠們的脊椎與骨盆基座——在發出警訊。如果你發現自家哈士奇最近上沙發的動作慢了半秒，或者在如廁排便後，後腿會不自覺地抖一下，這就是身體在告訴你，那些支撐牠狂奔的結構正在崩解。

別再迷信什麼「品種性格」這種廢話了。沒有哪隻狗會無緣無故在半夜消耗體能去大叫，那是非常耗能的行為，違背了生物演化的節能本能。當一隻以耐力著稱的北極犬選擇在休息時間不斷發聲，那通常是牠在試圖分散大腦對身體某處劇烈疼痛的注意力。

我上個月看過一隻才五歲的哈士奇，主人說牠最近半夜變得很愛「講話」，全家人都覺得好可愛。結果 X 光一照出來，兩邊的髖關節幾乎都已經脫出了一半，那是基因座上帶來的原罪，遺傳性的骨架缺陷。牠在叫，是因為牠每一次轉身都在磨骨頭。這種疼痛如果是發生在人類身上，早就領身心障礙手冊了，但牠還在那邊對你搖尾巴，這就是哈士奇最讓人心碎的地方。

所以，今晚如果你家那隻又開始對著月亮或是對著電視機長嚎，先別急著吼回去。拿出手電筒，看看牠站立時雙腿的間距有沒有變窄，看看牠起身時是不是先用前肢撐起全身重量。如果發現對勁，明天早上第一件事就是打給你的獸醫，說你要預約拍一張完整的髖關節與脊椎 X 光。那些半夜搜尋「哈士奇愛叫怎麼辦」的焦慮，大多時候只需要一張顯影清楚的片子就能解決。

我們總以為自己很了解這些朝夕相處的同伴，但其實我們連牠們為什麼開口說話都沒搞懂過。哈士奇不需要你跟牠對罵，牠需要的是你讀懂牠那些隱藏在噪音底下的、關於骨骼與神經的求救訊號。那種叫聲不是在抱怨你沒給牠零食，而是在說，牠那副為了冰原而生的軀殼，正在都市的水泥地與沙發間痛苦地崩塌。
