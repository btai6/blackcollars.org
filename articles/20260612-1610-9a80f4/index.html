誰在餵你的寵物吃過期罐頭？

版主　Sword Smith

在所謂的數位寵物圈裡，每個人都覺得自己是高明的飼主。你幫你的瀏覽器裝上各種外掛，就像給貓挑選最昂貴的進口主食罐，以為這樣就能擋掉那些令人煩躁的廣告彈窗，或者保護隱私不被大數據收割。但你有沒有想過，如果生產罐頭的工廠本身就是世界上最大的廣告商，他會讓你舒舒服服地吃掉每一口營養，而不順便塞點毒素進去嗎？最近圈子裡吵得最兇的，莫過於 Chrome 準備徹底掐斷 Manifest V2 擴充功能的脖子。這不是什麼技術升級，這是一場針對「不聽話寵物」的集體閹割。

那些號稱能完全阻擋廣告的插件，就像是給寵物戴上的防護面罩。但現在，工廠老闆說這個面罩太厚了，影響到他觀察寵物「進食」的效率。於是，他們推行 Manifest V3，美其名曰安全與效能，實際上是把面罩換成了一層薄如蟬翼的紗布。你以為你還戴著防護，其實你的數據早就被看光了。有趣的是，那些還在用 Chrome 的人，一邊抱怨著廣告阻擋器失效，一邊卻像被馴化的拉不拉多一樣，搖著尾巴繼續點開那個圓形的彩色圖標。這讓我想起某些地區的飼主，明知道某個品牌的飼料會導致寵物腎衰竭，卻因為贈品多、包裝好看，就安慰自己「下一批次應該會改善」。

在特定市場的討論區裡，這類話題總是充滿了某種斯德哥爾摩症候群式的辯論。有人問為什麼大家還在用 Chrome？這就像在問一個住在公寓的人為什麼不養一頭大象。生態系是致命的鎖鏈。你養了 Google 的全家桶，你的密碼、你的書籤、你的數位生命都寄生在那裡。這不是單純的工具選擇，這是領地依賴。某些開發者試圖在 Brave 或 Vivaldi 這些「避難所」裡尋求出路，聲稱內建的阻擋功能已經夠用。但我看著那些自豪的陳述只覺得荒謬。這就像是一個收容所告訴你，雖然我們不提供頂級醫療，但我們這裡的空氣比較自由。事實是，只要底層架構還是在 Chromium 的陰影下，你所謂的自由，不過是主子心情好時多給的一公分牽繩。

看看那些海外論壇的數據吧，不少資深用戶開始往 Firefox 遷徙。這不是因為 Firefox 有多完美，而是因為它是目前唯一還能讓「防護面罩」保有物理厚度的避難所。但在主流視野裡，這群人被視為偏執的少數派。這跟寵物產業的內幕如出一轍：那些堅持餵生食、堅持看成分表的硬核飼主，永遠比不上那些看廣告買大賣場飼料的普通人。廠商不在乎那一小撮有主見的人，他們要的是那 90% 懶得思考、只要能點開網頁就滿足的數位家畜。當 Manifest V2 消失的那天，你會發現你的數位寵物變得異常「順從」，牠不再反抗任何追蹤器，牠的行為變得透明且可預測。

我們現在面對的環境，是一個透明度極高但毫無隱私的培養皿。有些品牌宣稱「不作惡」，這句話現在聽起來比寵物食品包裝上的「全天然」還要諷刺。在商業邏輯面前，用戶的選擇權跟路邊的流浪動物沒什麼兩樣，隨時可以被清除，或者被重新定義。當工具不再為使用者服務，而是為工具的製造者服務時，這種關係就已經變質了。

如果你現在還能用著流暢的阻擋器，看著乾淨的網頁，那不過是緩刑期間的假象。當那道門關上，所有的數據都會變成餵養演算法的殘渣。我比較感興趣的是，當最後一個強效阻擋器失效時，那些口口聲聲說要捍衛隱私的專業用戶，是真的會選擇搬家，還是會乖乖接受這場數位閹割，然後在下一個討論帖裡繼續發牢騷，卻始終不敢按下那個「解除安裝」的按鈕？當你的數位寵物不再屬於你，你還打算繼續餵養牠多久？
