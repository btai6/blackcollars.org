別再安慰自己牠只是老了腳痠或剛才跳太高閃到腰

版主　Scholar

上週三深夜兩點，有個飼主傳了一張照片給我，家裡的柯基像尊佛像一樣，前半身挺得很直，但後半身卻歪向一側，兩隻後腿沒像平常那樣收好，而是像兩根沒感覺的木頭叉在地上。那位飼主問我：「醫師，牠是不是今天下午去草地跑太瘋，現在腿痠在偷懶？」我當時看著螢幕深深嘆了口氣，直接回傳一句話：別等明天早診了，現在就去有夜間急診的醫院掛號，記得找有神經外科或能拍電腦斷層的地方。

很多人對於「疼痛」的理解太過於擬人化，總覺得寵物如果真的很痛，應該會哀叫、會發抖，或是像電影演的那樣縮在角落。但事實上，犬貓對慢性或突發性劇痛的表現往往是沉默的。牠們不會抱怨，牠們只會試圖尋找一個「不那麼痛」的姿勢。如果你的狗突然換了一個非常不符合人體工學、甚至看起來有點滑稽的坐姿，而且你叫牠、拿零食引誘牠，牠依然維持那個姿勢紋絲不動，那通常不是牠在裝可愛，而是牠只要稍微挪動一公釐，那種神經被壓迫的電擊感就會讓牠崩潰。

特別是那些天生背部比較長的品種，像是臘腸、柯基，或是法鬥這種脊椎基因本來就不太穩定的犬種。牠們的椎間盤突出往往發生在一瞬間。你可能只是看牠跳下沙發，或者只是在家門口轉個身，那個位於脊椎骨之間的纖維環就破了，裡面的髓核直接衝出來壓迫神經。這時候的奇怪坐姿，其實是牠們身體最後的防線。牠們在利用肌肉的緊繃去支撐那個已經快斷掉的傳導路徑。

我遇過太多飼主，在這種關鍵時刻選擇「再觀察一晚」。他們會拿家裡的常備藥，甚至自己吃的止痛藥隨便塞給寵物，想說睡一覺起來就好。這是我聽過最危險的念頭。在脊椎受傷的黃金救援時間裡，每一小時都在倒數。神經細胞一旦缺血、受壓過久，那是不可逆的。等到第二天早上，你發現牠連後腿都拖在地上走，甚至已經失去深層痛覺時，那個時候拍 X 光可能都太遲了。

其實 X 光只是一個初步的篩檢，它能告訴我們骨頭有沒有移位、有沒有骨刺，但真正的魔鬼往往藏在軟組織裡。但我還是會叫飼主立刻去拍，為什麼？因為我們要排除最糟糕的情況。如果你看到一隻八歲的米克斯，平常動作靈活，突然間走路像踩在棉花上，坐下來的時候後腳一直打滑，這絕對不是腳痠。腳痠的狗會想辦法躺下來放鬆，但神經受壓迫的狗往往不敢躺，因為躺下的過程對脊椎是巨大的折磨。

還有一個很常被忽視的族群是高齡貓。貓是忍痛的大師，牠們的關節炎或脊椎問題隱藏得比狗還要深。當你發現家裡的長輩貓突然不愛跳上牠最愛的書櫃，或者上廁所的時候姿勢變得有點歪斜，甚至開始在貓砂盆邊緣徘徊卻不進去，這時候別再跟我說什麼「老了體力不好」。去照張片子看看吧，很多時候那種奇怪的停頓感，都是因為骨贅在磨損神經。

我常跟診間的實習生說，看診不只是看檢驗數值，更多時候是看那個「違和感」。一個正常的生物，如果不受傷，是不會強迫自己維持奇怪姿勢的。人類腳痠會拉筋、會揉捏，但狗不會，牠們只會僵在那裡。如果你發現家裡的毛小孩半夜不睡覺，盯著地板發呆，身體擺出一個你從沒見過的奇怪角度，請立刻拿起手機錄影，然後去醫院。

這不是在嚇唬人。我見過太多在診間哭著說早知道昨晚就送來的案例。如果是肌肉拉傷，拍個 X 光頂多花點錢買個安心；但如果是神經受損，那一晚的遲疑，可能就是換來餘生都要幫牠擠尿和推輪椅的代價。我們這種當獸醫的，最怕聽到的就是「牠看起來還好，應該沒事」。在止痛與致殘之間，那個奇怪的坐姿就是牠發出的最後通牒，只是牠沒辦法開口喊救命而已。

尤其是那些五、六歲正值壯年的品種犬，飼主最容易掉以輕心。總覺得牠還年輕，體力這麼好，怎麼可能跳一下就癱瘓。但基因這種事是沒在講道理的，特定的基因座決定了牠們軟骨發育不全的特質，這也意味著牠們的脊椎天生就是比別人脆弱。這不是你多餵兩顆葡萄糖胺就能解決的問題，這是結構性的缺陷。當結構崩塌的時候，唯一的辦法就是醫療介入，而不是等待奇蹟發生。

半夜三點，如果你還在電腦前搜尋「狗、奇怪坐姿、腳痠」，聽我一句，關掉網頁。去把外出籠拿出來，摸摸牠的背，看牠會不會回頭瞪你或露出牙齒，如果牠連回頭的動作都顯得很吃力，那真的沒什麼好猶豫的了。那張 X 光片不只是為了診斷，它是為了幫你找回那個能正常跑跳的牠。別讓牠在那種無聲的劇痛中熬到天亮。
