貓界名模跟狗界大食怪的標籤

版主　Scholar

剛才在急診室接了一通電話，對方的三花貓因為半夜想睡覺被小主人吵醒，憤而賞了全家人一套組合拳。那位飼主在電話裡語氣充滿委屈，覺得自己養到一隻隨機引爆的炸彈。我聽了忍不住笑了，上週才剛送走一隻因為吞掉一整條髒毛巾而動手術的拉不拉多，牠的主人那時候也在診間發呆，問我說：醫生，牠到底是餓死鬼投胎，還是腦袋裡根本沒有飽足感這三個字？

其實這兩種極端表現在我們臨床醫生眼裡，背後都有很硬的生理依據，不是飼主教不好，更不是牠們故意要找碴。

先說那個讓無數飼主又愛又恨的三花貓脾氣。很多研究跟文獻都提過，貓的毛色跟性格有著神祕的關聯，這不是玄學。三花貓幾乎九成九以上都是母貓，這跟牠們的 X 染色體脫不了關係。在遺傳學上，決定毛色的黑色與橘色基因都位在 X 染色體上，當一隻貓同時擁有兩條 X 染色體，且分別帶有這兩種顏色基因時，就會出現這種拼布般的毛色。

這種遺傳機制在生物學上叫做「X 染色體去活化」。這聽起來很硬，但我想說的是，三花貓的這種遺傳多樣性，往往伴隨著非常強烈的「母系天性」。母貓在野外為了保護後代，危機意識本來就比公貓高出好幾個層級。妳可以想像，一隻三花貓的基因庫裡，刻滿了那種「隨時準備好要跟掠食者拼命」的防衛機制。

我在診間最常看到的狀況是，三花貓對環境的變動極度敏感。如果你移動了客廳的一個盆栽，或是換了一個牌子的貓砂，其他貓可能只是去聞一聞，但三花貓會覺得整個世界都要崩塌了。牠們的壞脾氣，其實是一種過度防禦。我常跟飼主開玩笑說，你養的不是一隻貓，是一台裝了超靈敏雷達的防空炮塔。那種突如其來的哈氣或出爪，在牠們的腦回路裡，是「先發制人」的生存法則。這不是因為牠們不愛你，而是牠們的基因告訴牠們：這個世界充滿危險，隨時保持緊繃才是活下去的唯一路徑。

反觀拉不拉多，牠們的故事就顯得單純——或者說，顯得更像是一場生理上的悲劇。如果你覺得你家的拉不拉多是一個永遠填不滿的黑洞，這真的不是你的錯覺。

在拉不拉多跟平毛尋回犬這個品種的基因序列裡，有一個很著名的缺陷，叫做「POMC 基因突變」。這個基因原本的職責是負責調節能量代謝，並在吃飽的時候釋放信號告訴大腦：嘿，可以停下來了。但大約有四分之一的拉不拉多，這個開關是壞掉的。這意味著，無論牠剛剛吞掉的是一碗頂級飼料，還是你掉在地上的臭襪子，牠的大腦始終接收不到「飽了」這個訊息。

牠們是真的、發自內心地覺得自己快餓死了。

這種生理缺陷讓拉不拉多在面對食物時，展現出一種幾近瘋狂的執著。我見過太多拉不拉多為了吃，可以做出違反物理常規的舉動。上個月那隻吞毛巾的傢伙，術後清醒的第一件事，竟然是去舔護士掉在桌上的餅乾屑。很多人覺得拉不拉多很憨厚、很好教，其實那只是因為牠們願意為了任何一塊能塞進嘴裡的熱量出賣靈魂。在訓練師眼裡，這是優點，因為牠們的「食物動力」高得驚人。但在飼主眼裡，這簡直是場無止境的守衛戰。

有趣的是，這種遺傳缺陷在演化初期其實是種優勢。作為一種水獵犬，拉不拉多需要在寒冷的水域裡反覆打撈獵物，身上必須囤積大量的皮下脂肪。那種「見到熱量就吞」的本能，讓牠們的祖機能夠在惡劣環境下存活下來。只是到了現代，當這種本能被關進二十幾坪的電梯大樓，面對的是每天定時定量的商業乾糧時，原本的生存優勢就變成了肥胖與慢性病的詛咒。

我有時候看著診間裡的這些病患，會覺得人類在培育這些品種時，其實挺自私的。我們為了追求某種特定的外貌、某種極致的工作能力，在牠們的基因裡留下了這些難以磨滅的刻痕。

三花貓的敏感與警覺，讓牠們成為最優雅但也最難以捉摸的家庭成員；而拉不拉多的貪食與熱情，讓牠們成為最療癒但也最讓荷包失血的伴侶。我們常常用擬人化的方式去解讀牠們的行為，說三花貓「傲嬌」、說拉不拉多「貪吃」，但撕開這些擬人化的標籤後，剩下的其實都是生存的本能。

你沒辦法叫一隻三花貓不要那麼神經質，就像你沒辦法叫一隻拉不拉多大腦裡的開關突然修復一樣。這就是為什麼我總是在半夜接到這些焦慮的電話。飼主們總是在尋求一個「解決方案」，希望有個魔法能讓貓變溫柔、讓狗變淑女。但現實是，當你選擇了這個品種，你就同時繼承了牠們這幾百年來演化累積下來的所有包袱。

與其說是我們在「養」牠們，不如說我們是在跟這些古老的基因密碼共同生活。當你理解了那隻三花貓之所以對你哈氣，是因為牠的 X 染色體正在尖叫著保護領地；當你理解了那隻拉不拉多之所以翻開垃圾桶，是因為牠的 POMC 基因正處於永恆的飢荒中，你也許就能稍微放下那種被背叛的憤怒。

說到底，我們對寵物的很多抱怨，其實都來自於我們對生命本質的不理解。我們想要的是一個完美的、符合預期的工業產品，但帶回家的卻是一個充滿缺陷、卻又無比真實的生命。那些半夜的恐慌、那些家具上的齒痕、那些莫名其妙的抓傷，都是這份真實的一部分。

下次當你家的三花貓莫名其妙又賞了你一拳，或是你家的拉不拉多又在盯著空碗發呆時，別急著去搜尋什麼「行為糾正」。試著想一下，牠們只是在用自己的方式，在現代鋼筋水泥的叢林裡，努力履行那份寫在血液裡的、殘缺卻古老的合約。這不是誰的錯，這只是生命最初的模樣。
