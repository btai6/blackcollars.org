一隻鵪鶉每天噴 1.2 克氮排泄物，算完

版主　渡鴉

別再被那些國外博主家裡的精緻鵪鶉籠給騙了，什麼放在客廳當軟裝、一邊喝咖啡一邊等著撿蛋，那些畫面背後沒拍出來的，是這隻不到兩百公克的小禽類驚人的生理數據。我上週才跟我那個做獸醫防疫的朋友喝兩杯，他剛處理完一批農場的檢疫，跟我抱怨說現在一堆人把鵪鶉當貓狗在養，卻完全沒搞清楚這種「飛行噴泉」的威力。

我們來算這筆帳。一隻成年的日本鵪鶉，體重頂多 150 到 200 公克，但牠每天排出的氮含量大約是 1.2 公克。你可能覺得 1.2 公克聽起來沒什麼，但我告訴你，如果按體重比例換算成一個 70 公斤的成年人，那相當於你每天要產出將近半公斤的純氮廢棄物。這是一個什麼概念？這代表牠的代謝速度快到像是開了外掛，進去的飼料跟出來的廢物幾乎是無縫接軌。鵪鶉沒有膀胱，為了減輕重量好隨時起飛，牠們的生理構造決定了這是一場隨時隨地的噴發。

我家隔壁那個大學生，前陣子看短影音覺得鵪鶉蛋很可愛，買了兩隻放在租屋處的小陽台。結果不到三天，他就跑來問我為什麼陽台的味道像是在夏天的高速公路上撞到一輛載滿雞隻的貨車。我進去一看，他用那種精緻的鐵絲籠，下面鋪了一層薄薄的木屑。那 1.2 公克的氮在狹窄空間裡，加上台灣這種濕熱天氣，分解出來的氨氣濃度高到會燻眼睛。我直接跟他說，你這不是在養寵物，你是在家裡蓋一個小型化工廠。

很多人買寵物保健品或是飼料，只會看包裝上的漂亮照片，卻從來不看標籤上的粗蛋白質比例。鵪鶉飼料的蛋白質通常要求在 24% 以上，因為牠們要產蛋、要維持高體溫。這麼高的蛋白質攝入，轉化出來的尿酸鹽就是那層白白的東西。如果你以為那是普通的小鳥排泄，你就太天真了。那種強鹼性的物質，幾天不清理就能腐蝕掉便宜的籠子底盤。我朋友老婆之前養過一隻，放在陽台的磁磚上，半年後磁磚表面的釉料全都被蝕光了。

這就是行銷話術最坑人的地方。廠商會告訴你鵪鶉好養、空間需求小、每天有蛋吃，但他們不會告訴你，為了應付那每天 1.2 公克的氮，你需要投入的清潔勞動力跟水費，早就超過那幾顆蛋的價值。這讓我想起美國那邊一些「自給自足」派的飼主，他們鼓吹在公寓客廳養鵪鶉，甚至發明了一種叫做「鵪鶉尿布」的東西。那簡直是養寵物界的奇觀，把一隻本該在草叢裡鑽來鑽去的小鳥，塞進一個充滿人工纖維的布包裡，只為了掩蓋牠那驚人的代謝數據。

我看過最離譜的數據是，有些進口的高端寵物禽類除臭噴霧，一瓶五百毫升要賣六百多塊。我看了一下成分，主要就是些生物酶或者是植萃精華。說實話，這跟你在處理實驗室化學溢漏沒什麼兩樣，本質上都是在跟那些氮分子搏鬥。你以為買的是生活質感，其實你是在為這隻小生物的生存機制買單。鵪鶉的智商在鳥類排名中並不算頂尖，大概只有五、六歲小孩的感知程度，牠們不會知道你為了那 1.2 公克多崩潰，牠們只會在你的除臭噴霧噴完後的兩分鐘，再度完成下一次精確的噴發。

那些在網路上分享「鵪鶉進客廳」的飼主，背後不是有強大的全自動清理系統，就是嗅覺已經產生了生理性的適應。我那個獸醫朋友說，他每次去巡視禽類養殖場，最怕的不是禽流感，而是那種濃縮到極致的氨氣味。他說那是「生命力的惡臭」。當你把這種大規模集約養殖的生物縮小規模放進你的臥室，那種 1.2 公克的氮就不再只是個化學名詞，而是每天二十四小時與你共存的生物現實。

大家在買寵物之前，真的該把化學週期表拿出來複習一下。你以為養的是可愛的球狀生物，其實你養的是一組不斷在運作的生化反應爐。那 1.2 公克的氮，就是這個反應爐每天雷打不動的產出。你算過你家地板、你的肺，以及你對「萌寵」的幻覺，能不能承受這每天一點一滴累積起來的化學攻勢嗎？下次看到有人在推坑養鵪鶉，先把這個數字砸在他臉上，問他願不願意每天在家裡處理這種強效氮肥。這不是愛不愛的問題，這是純粹的數學跟物理現實。
